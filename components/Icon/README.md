# Icon

Every glyph in the system, drawn in `currentColor`: the 13 GBIF content-type icons (green), header and control glyphs, Material action glyphs and social discs.

- Content-type icons are the GBIF set — use them at 40/20/16px as in the XD icon sheet, in brand green.
- Consumer supplies `name` (see `GBIF.iconNames`), `size` and, for meaningful icons, `title`.
