# Pill

2026 content-type pill: icon + caps label in brand green on `brand-soft`, fully rounded. Marks what kind of thing a search result is.

- One pill per result, top-left of the card. Use the matching `type` so icon and wording stay consistent.
- Labels are 12px — green on `brand-soft` is 3.1:1, so the icon and the card title carry the meaning too.
- Consumer supplies `type` (news, event, data-use, project, programme, tool, document, occurrence-dataset, checklist-dataset, publisher, species, page, resource) or `icon` + children for a custom one.
