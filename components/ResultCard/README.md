# ResultCard

2026 search-result card (698px): content-type Pill or TypeLabel, title link, two-line description, publisher meta line, optional 169×120 thumbnail, and a footer of CountTags. White, `radius-xs`, `shadow-card`.

- Stack with `space-4` between cards; group by type with a hairline between groups.
- Consumer supplies `type`, `pill`, `title`, `href`, `description`, `meta` (+ `metaIcon`), `image`, `counts` ({icon, label}).
