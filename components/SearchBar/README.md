# SearchBar

Search input with a trailing search glyph, in four forms: `raised` (58px, `shadow-raised`, floats on imagery and the 404 page), `flat` (40px on `surface-sunken`), and outlined S (14px) / M (16px) inside filter popovers.

- One raised search per page at most.
- Consumer supplies `placeholder`, `value`, `label` (for screen readers) and handles submit.
